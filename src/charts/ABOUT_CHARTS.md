# Data Visualisation

1. Easy Understanding of data. It saves more time because we can quickly analyse the data.
2. For Story Telling
3. Data Quality Checks

## Python based Visualisation libraries:

| Library              | Capabilities                           |
| -------------------- | -------------------------------------- |
| **matplotlib** | More customization on my graph / chart |
| **seaborn**    | For beautification                     |
| **plotly**     | Creating interactive charts            |

## Choosing between the charts

### By Analysis

| Analysis               | Purpose                                                                | Options                                                 |
| ---------------------- | ---------------------------------------------------------------------- | ------------------------------------------------------- |
| **Univariate**   | To understand the quality of one feature                               | _Countplot_, _Histogram_, _Boxplot_, _PieChart_ |
| **Bivariate**    | To understand the quality/relationship between**two features**   | *Barplot*, *Scatterplot*                              |
| **Multivariate** | To understand the relationship between**more than two features** | *Parplot*, *Heatmap*                                  |

### Other Charts:

- Lineplot, Time series
